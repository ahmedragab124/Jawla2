2️⃣ مخطط إضافة وجهة سياحية (Add Destination Wizard Flow)

خطوات الإضافة الـ 5 المقسمة إلى مكونات مستقلة وتأكيد البيانات وإرسالها لـ Supabase.

flowchart LR
    StartDest([بداية النموذج AddDestination]) --> Step1["Step 1: StepInfo (Name, Slug ID, Weather)"]
    Step1 --> Val1{تأكيد البيانات المطلوبة؟}
    Val1 -->|نقص بيانات| ToastErr1["toast.error()"]
    Val1 -->|صحيح| Step2["Step 2: StepImages (Hero Image, Card Image, Title)"]
    
    Step2 --> Val2{تأكيد الصور؟}
    Val2 -->|نقص| ToastErr2["toast.error()"]
    Val2 -->|صحيح| Step3["Step 3: StepDetails (Description, History)"]
    
    Step3 --> Val3{تأكيد الوصف؟}
    Val3 -->|نقص| ToastErr3["toast.error()"]
    Val3 -->|صحيح| Step4["Step 4: StepLocation (Latitude, Longitude)"]
    
    Step4 --> Val4{تأكيد الإحداثيات؟}
    Val4 -->|نقص| ToastErr4["toast.error()"]
    Val4 -->|صحيح| Step5["Step 5: StepExperiences (Exp Description + Dynamic JSON List)"]
    
    Step5 --> Submit["حفظ النموذج insert()"]
    Submit --> SupabaseDB[("Supabase DB: destinations table")]
    SupabaseDB --> ToastSuccess["toast.success() + Reset Form"]

4️⃣ تسلسل الذكاء الاصطناعي وحجز المرشدين (AI & Booking Sequence)

sequenceDiagram
    autonumber
    actor Tourist as السائح
    participant UI as AIPlannerPage.jsx
    participant Hook as useAIPlanner.js
    participant Gemini as Gemini API (gemini.js)
    participant DB as Supabase (ai_trips)

    Tourist->>UI: إدخال الوجهة، الأيام، الميزانية، والاهتمامات
    UI->>Hook: generatePlan(formData)
    Hook->>Gemini: إرسال الـ Prompt المنسق (geminiPrompt.js)
    Gemini-->>Hook: إرجاع JSON البرنامج السياحي اليومي
    Hook-->>UI: عرض الجدول والبرنامج السياحي
    Tourist->>UI: النقر على "حفظ الرحلة"
    UI->>Hook: savePlan(result)
    Hook->>DB: INSERT into ai_trips table
    DB-->>Hook: تم الحفظ بنجاح
    Hook-->>UI: toast.success() + إضافة الرحلة للبروفايل

📁 تفاصيل وتصنيف ملفات المشروع (File-by-File Technical Table)

مسار الملف (File Path) النوع (Type) البيانات الممررة (Props / Parameters) الوظيفة والتدفق (Function & Workflow)
src/main.jsx Root Entry — تهيئة React Root وربط الـ Router، الـ AuthProvider والـ ToastContainer العالمية.
src/supabase.js DB Client VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY تصدير كائن الاتصال بـ Supabase للتعامل مع قاعدة البيانات والمصادقة.
src/app/App.jsx Router Hub — إدارة شجرة التوجيه كاملة وتنسيق المسارات العامة والمسارات المحمية للأدمن.
src/layout/MainLayout.jsx Layout <Outlet /> قالب واجهات الموقع العامة (Navbar في الأعلى + المحتوى + Footer في الأسفل).
src/layout/AdminLayout.jsx Layout <Outlet /> قالب لوحة تحكم الأدمن (القائمة الجانبية Slider + المحتوى الرئيسي).
src/shared/Slider.jsx Component onClose (optional) القائمة الجانبية المتطورة للأدمن مع مجموعات قابلة للطي للوجهات والمعالم.
src/features/auth/context/AuthContext.jsx Context — إدارة حالة تسجيل الدخول، المستخدم الحالي، والصلاحيات (Tourist, Guide, Admin).
src/features/auth/components/RequireRole.jsx Guard children, allowedRoles حماية المسارات وتأكيد يمتلك المستخدم الدور المسموح للزيارة.
src/dashboards/admin/components/Attraction/Addattraction.jsx Orchestrator — منسق نموذج إضافة المعالم 4 خطوات، يدير الـ State والـ Validation والتنبيهات.
src/dashboards/admin/components/Destination/AddDestination.jsx Orchestrator — منسق نموذج إضافة الوجهات 5 خطوات (بما فيها قائمة التجارب Dynamic JSONB).
src/features/ai-planner/hooks/useAIPlanner.js Custom Hook formData إدارة الطلبات الموجهة لـ Google Gemini API وتخزين الرحلة المتولدة في Supabase.
src/pages/NotFoundPage.jsx Page — صفحة 404 المصممة بهوية الموقع، تحتوي على بوصلة متحركة وأزرار عودة سريعة.
